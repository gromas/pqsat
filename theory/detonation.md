Спецификация алгоритма: Детонационный решатель (DetSolv)

1. Исходные данные и постановка задачи

Пусть задана булева формула в конъюнктивной нормальной форме с тремя литералами на клоз (3-КНФ):

·  V = \{v_1, v_2, \dots, v_n\}  — множество пропозициональных переменных.
·  C = \{c_1, c_2, \dots, c_m\}  — множество клозов.
· Каждый клоз  c_j \in C  представляет собой дизъюнкцию  c_j = (l_{j1} \lor l_{j2} \lor l_{j3}) , где литерал  l  — это либо переменная  v , либо её отрицание  \neg v .

Требуется: Определить, выполнима ли формула  F  (SAT), или невыполнима (UNSAT).

---

2. Фаза 1: Структурная декомпозиция (P/Q-разложение)

2.1. Определение вершинного покрытия

Рассматривается гиперграф  H , где каждая гипервершина — переменная, а каждое гиперребро — множество переменных, встречающихся в одном клозе.
Необходимо найти множество  P \subset V , являющееся вершинным покрытием для  H . Остаток обозначается  Q = V \setminus P .

2.2. Жадный алгоритм построения покрытия

1.  T := \{ (x, y, z) \mid \exists c \in C : \text{переменные } x, y, z \text{ входят в } c \} .
2.  \text{uncovered} := T ;  P := \emptyset .
3. while  \text{uncovered} \neq \emptyset :
   · Выбрать переменную  v \in V \setminus P , максимизирующую количество инцидентных непокрытых троек.
   ·  P := P \cup \{v\} .
   · Удалить из uncovered все тройки, содержащие  v .

2.3. Результат декомпозиции

Полученное разложение обладает свойством:

\forall c \in C: \text{Vars}(c) \cap P \neq \emptyset

---

3. Фаза 2: Классификация клозов

Все клозы классифицируются по соотношению переменных из  P  и  Q :

1. Тип A (Шапка,  P_3 ):  \text{Vars}(c) \subseteq P .
2. Тип B (Двудольные  P_2Q_1 ):  |\text{Vars}(c) \cap P| = 2 ,  |\text{Vars}(c) \cap Q| = 1 .
3. Тип C (Двудольные  P_1Q_2 ):  |\text{Vars}(c) \cap P| = 1 ,  |\text{Vars}(c) \cap Q| = 2 .
4. Тип D (Несуществующие  Q_3 ):  \text{Vars}(c) \subseteq Q . По построению  P , таких клозов нет.

---

4. Фаза 3: Построение графов зависимостей

Вводится понятие состояния переменной:  \text{State}(x) \in \{ \text{UNDEF}, 0, 1, \text{CONFLICT} \} .

4.1. Граф влияния  G_{P \to Q} 

Для каждого клоза типа  P_2Q_1 :  (p_i^{s_i} \lor p_j^{s_j} \lor q_k^{s_k}) :

· Строится ребро:  (p_i, p_j) \Rightarrow q_k .
· Семантика детонации: Если  \text{State}(p_i)  и  \text{State}(p_j)  зафиксированы так, что  p_i^{s_i} = \text{False}  и  p_j^{s_j} = \text{False} , то переменная  q_k  вынуждена принять значение, обращающее  q_k^{s_k}  в истину (иначе клоз нарушен).

4.2. Граф влияния  G_{Q \to P} 

Для каждого клоза типа  P_1Q_2 :  (p_i^{s_i} \lor q_j^{s_j} \lor q_k^{s_k}) :

· Строится ребро:  (q_j, q_k) \Rightarrow p_i .
· Семантика детонации: Если  \text{State}(q_j)  и  \text{State}(q_k)  зафиксированы так, что  q_j^{s_j} = \text{False}  и  q_k^{s_k} = \text{False} , то переменная  p_i  вынуждена принять значение, обращающее  p_i^{s_i}  в истину.

---

5. Фаза 4: Процедура распространения (Детонация)

5.1. Алгоритм волнового распространения

Функция Propagate(Seed) принимает на вход начальное присвоение подмножества переменных.

```
Вход: Множество инициированных переменных I с присвоенными значениями.
Выход: (Assignment A, Status) где Status ∈ {SAT, CONFLICT}.

A := I   // Текущее присвоение
queue := I (все элементы) // Очередь на обработку (или флаг изменения)

while (queue не пуста) {
    x := pop(queue)

    // Проверка клозов, где x участвует в левой части правил
    // Случай 1: x ∈ P. Ищем правила (x, p2) => q (из G_P→Q)
    Для каждого правила (x, y) => z, где x,y ∈ P, z ∈ Q:
        Если State(y) определено и оба литерала ложны:
            Присвоить z значение, делающее его литерал истинным.
            Если z уже имеет другое значение: return CONFLICT.
            Добавить z в queue.

    // Случай 2: x ∈ Q. Ищем правила (x, q2) => p (из G_Q→P)
    Для каждого правила (x, y) => z, где x,y ∈ Q, z ∈ P:
        Если State(y) определено и оба литерала ложны:
            Присвоить z значение, делающее его литерал истинным.
            Если z уже имеет другое значение: return CONFLICT.
            Добавить z в queue.

    // Случай 3: Обработка "Шапок" (P3)
    Для каждого клоза (p_i ∨ p_j ∨ p_k) типа P3:
        Если два из трех литералов ложны при текущем присвоении:
            Присвоить третьему переменной значение, делающее его истинным.
            Если переменная уже имеет другое значение: return CONFLICT.
            Добавить переменную в queue.
}
return (A, SAT)
```

5.2. Прямая и обратная волны

· Прямая волна: Запуск Propagate от подмножества  Q .
· Обратная волна: Запуск Propagate от подмножества  P .

5.3. Проверка совместности

Два присвоения  A_1  и  A_2  (например, от прямой и обратной волны) совместны, если:

\forall v \in \text{dom}(A_1) \cap \text{dom}(A_2): A_1(v) = A_2(v)

6. Фаза 5: Поиск детонирующего множества  S 

6.1. Определение

Множество  S \subseteq Q  называется детонирующим, если фиксация его элементов и применение процедуры Propagate детерминирует значения всех остальных переменных (или сводит проблему к 2-SAT).

6.2. Построение графа причинности

Строится ориентированный граф  G_{\text{caus}} , вершинами которого являются переменные  Q . Ребро  q_a \to q_b  строится, если существует путь детонации от  q_a  к  q_b  через  P :

q_a \xrightarrow{P_1Q_2} p_x \xrightarrow{P_2Q_1} q_b

6.3. Эвристический поиск минимального  S 

Так как поиск минимального  S  может быть трудоемким, используется жадная стратегия, направленная на разрыв циклов в графе  G_{\text{caus}} .

1. Вычислить вес переменной  q \in Q :
   w(q) = \alpha \cdot \deg_{P_2Q_1}(q) + \beta \cdot \deg_{P_1Q_2}(q)
   где  \alpha > \beta  (приоритет отдается влиянию на  Q ).
2. Найти сильно связные компоненты (SCC) в  G_{\text{caus}} .
3. while (существуют SCC размера > 1):
   · Выбрать  q  с максимальным  w(q)  в SCC.
   ·  S := S \cup \{q\} .
   · Удалить  q  из графа и пересчитать SCC.
4. В результате  S  — это множество "разрывателей циклов".

7. Полный алгоритм решения

```
Алгоритм DetonationSolver(CNF F):

1.  // Фаза декомпозиции
    (P, Q) = GreedyVertexCover(F)

2.  // Фаза классификации
    (C_P3, C_P2Q1, C_P1Q2) = ClassifyClauses(F, P, Q)

3.  // Фаза построения зависимостей
    BuildGraphs(C_P2Q1, C_P1Q2)

4.  // Фаза поиска детонирующего множества
    S = FindDetonatingSet(Q, Graphs)  // |S| = k

5.  // Фаза перебора и проверки
    Для каждого из 2^k возможных значений σ для S:
        A = σ
        (A, status) = Propagate(A ∪ P_init) // Распространяем влияние
        if status == CONFLICT:
            continue

        // После Propagate могут остаться свободные переменные
        // Оставшаяся формула F' является 2-КНФ (или содержит только P3 клозы).
        if Is2CNF(F') {
            (sat, A_full) = Solve2CNF(F')
            if not sat: continue
            A = A ∪ A_full
        }

        // Проверка оставшихся P3 клозов
        if CheckAllClausesSatisfied(A, C):
            return SAT

6.  return UNSAT
```

8. Теоретические оценки

8.1. Сложность

· Построение P/Q:  O(m \cdot n)  при эффективной реализации подсчета вхождений.
· Поиск  S :  O(|Q|^2)  для поиска SCC и жадного удаления.
· Перебор:  O(2^{|S|} \cdot (m + n)) .

Общая временная сложность:  O(2^{|S|} \cdot \text{poly}(n, m)) .

8.2. Корректность

Алгоритм корректен, так как он осуществляет полный перебор только по переменным  S , а все остальные значения выводятся детерминированно через отношение импликаций (клозов), либо решаются полиномиальным 2-SAT алгоритмом. Если ни одно из назначений  S  не приводит к выполнению всех клозов, формула невыполнима.

8.3. Гипотеза о мощности  S 

Для случайных 3-КНФ в области фазового перехода ожидается, что  |S| \approx \sqrt{n} . Для структурных задач (например, кодирование схем)  |S|  может быть константой или логарифмом, что обеспечивает эффективность алгоритма.
